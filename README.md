# ООО «Элтехника» — лендинг-гибрид (Итерация 0)

Проект на Next.js 14 (App Router) с TypeScript и Tailwind CSS.

## Что сделано в Итерации 0
- Базовая структура проекта.
- Дизайн-токены (цвета, тени, контейнер, радиусы).
- Глобальные стили и подключение шрифта с кириллицей.
- SEO-заготовка (metadata, robots, sitemap).
- Конфигурация для дальнейшей реализации лендинга-гибрида.

## Команды
```bash
npm install
npm run dev
npm run build
npm run lint
```
